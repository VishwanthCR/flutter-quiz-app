# Flutter Quiz App 🎯

A **quiz application built with Flutter** as part of my mobile application development journey.

The project is currently **under development** and is being built to explore Flutter fundamentals, UI development, user interaction, and application state management.

> 🚧 **Status: Under Development**

## 📱 About the Project

Flutter Quiz App is a mobile quiz application designed to provide users with an interactive way to answer questions and test their knowledge.

The project is currently being developed incrementally, with additional features and improvements planned for future versions.

## 🛠️ Tech Stack

* **Flutter**
* **Dart**
* **Android**
* **Material UI**

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* [Flutter SDK](https://docs.flutter.dev/get-started/install)
* Dart SDK
* Android Studio or Visual Studio Code
* An Android emulator or physical Android device

### Clone the Repository

```bash
git clone https://github.com/VishwanthCR/flutter-quiz-app.git
cd flutter-quiz-app
```

### Install Dependencies

```bash
flutter pub get
```

### Run the Application

```bash
flutter run
```

You can also run the project using an Android emulator or a connected physical device.
